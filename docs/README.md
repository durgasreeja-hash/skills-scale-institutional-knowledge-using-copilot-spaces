# OctoAcme Project Management Docs

This directory contains OctoAcme's project management guidance. Use this page as a starting point, then follow the links below for the detailed process and role guidance.

## Project lifecycle at a glance

OctoAcme begins by validating a project's need, intended outcomes, stakeholders, and go/no-go decision. Approved work is planned as prioritized, estimated increments with clear acceptance criteria, owners, milestones, a Definition of Done, and identified risks and dependencies. During execution, the team tracks work on a project board, communicates regularly, tests changes, and escalates blockers through the appropriate roles. Releases use readiness checks, deployment verification, and rollback planning. Retrospectives close the loop by turning lessons into owned, tracked improvement actions.
